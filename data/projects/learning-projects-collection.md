## 🔬 Project Overview

Three self-contained learning builds, each demonstrating a different layer:

| Project | What it proves |
|---------|---------------|
| **MatchCards ("magic-memory")** | React memory-card game with Testing Library + Jest tests |
| **react-job-api / react-job-project** | Express + uuid REST API + React (Vite, Tailwind, react-router, react-toastify) job-board app |
| **gemini-form-auto-filler** | Chrome extension (manifest.json, background.js, content.js) with React UI and @google/genai — AI-powered form auto-filling |

## 🛠️ Technical Implementation

**Frontend**: React, Vite, Tailwind, react-router, react-toastify
**Backend**: Express, uuid
**Extension**: Chrome Extension APIs, Google GenAI (@google/genai)
**Testing**: Jest, Testing Library
