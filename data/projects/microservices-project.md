## 🔬 Project Overview

A microservices-project with order-service, payment-service, and user-service, docker-compose orchestration, nginx.conf gateway routing, and AppDynamics machine-agent instrumentation.

## ✨ Key Features

🧩 **Service Decomposition** - Order, payment, and user as independently deployable services
📦 **Docker Compose** - One-command local stack
🌐 **Nginx Gateway** - Reverse-proxy routing
📈 **Observability** - AppDynamics machine-agent instrumentation
