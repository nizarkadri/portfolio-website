## 🔬 Project Overview

Tested and optimized open-source generative models from Hugging Face and CivitAI using ComfyUI in a local GPU environment; solved complex dependency and build issues involving CUDA and xFormers; fine-tuned Stable Diffusion and StyleGAN3.

**🎯 Problem**: Local generative-model toolchains are fragile — reproducible environment setup and troubleshooting is the real product.

## ✨ Key Features

🎨 **Local Inference** - ComfyUI workflows for Hugging Face / CivitAI models
🧬 **Fine-Tuning** - Stable Diffusion and StyleGAN3 fine-tunes; PhotoMaker V2 identity-retention work with Kohya GUI
🔧 **Build Fixes** - Resolved complex MSVC/CUDA/xFormers build conflicts with a documented reproducible install guide

## 🛠️ Technical Implementation

**Stack**: Hugging Face, ComfyUI, Stable Diffusion, StyleGAN3, CUDA, xFormers, Kohya GUI
