## 🔬 Project Overview

An Instagram-style multimedia social feed on MongoDB — Express, Mongoose, Multer + GridFS storage, react-h5-audio-player and react-loader-spinner in the client.

## ✨ Key Features

🖼️ **Multimedia Feed** - Image/video posts with audio playback
💾 **GridFS Storage** - Binary media stored via Multer + GridFS
⚡ **Polished States** - Loader states and responsive feed UI

## 🛠️ Technical Implementation

**Backend**: Express, Mongoose, Multer + GridFS
**Frontend**: React with react-h5-audio-player, react-loader-spinner
