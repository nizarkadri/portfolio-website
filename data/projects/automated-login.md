## 🔬 Project Overview

Automated password changing and login for a website: Python software performing web scraping to fetch and fill required fields, trained IBM Watson Assistant to solve CAPTCHA questions, and OTP fetched from email using the Gmail API.

## 🛠️ Technical Implementation

**Automation**: Python, selenium, web scraping
**CAPTCHA**: IBM Watson Assistant
**OTP**: Gmail API
