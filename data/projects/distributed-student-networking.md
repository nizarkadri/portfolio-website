## 🔬 Project Overview

A virtual community platform where students create/join interest-based groups with video conferencing, real-time chat, and shared event calendars.

**🎯 Problem**: Students need a persistent online community organized by interest, not just course enrollment.

## ✨ Key Features

👥 **Interest Groups** - Create and join interest-based groups
🎥 **Video Conferencing** - Built-in group video calls
💬 **Real-Time Chat** - Live messaging within groups
📅 **Shared Events** - Common calendars for group activities

## 🛠️ Technical Implementation

**Backend**: Node.js, Express.js, IBM Db2, REST APIs; GraphQL API for real-time updates and performant data interactions, asynchronous processing and rendering optimizations for concurrent user access
