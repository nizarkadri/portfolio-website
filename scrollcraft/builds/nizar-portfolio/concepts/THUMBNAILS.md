# Project thumbnails: prompts for the pale style

Replace the 14 dark, orange-toned covers in `public/images/Projects/<slug>.webp`. Same file names, so nothing in the code changes.
Format: 4:3, at least 1k (2k if they will also be used as case-study covers). No text, no logos, no UI screenshots.

## To run in Claude chat (where Higgsfield unlimited works)

Paste this, then the preamble and the 14 subjects below:
"Using Higgsfield with my unlimited generations only (never credits), make 14 images with nano_banana_2 at 2k, aspect 4:3.
For each, the prompt is the style preamble followed by 'Accent: <accent>. Subject: <subject>.' from the list."
When they are done, tell Claude Code; it fetches them from the same Higgsfield account and puts them in place.

## Style preamble (paste in front of every prompt, unchanged)

Bright, airy editorial 3D still life for a software portfolio. A pale ice-white seamless studio, soft daylight from the upper left,
gentle contact shadows, matte materials with one or two glass or polished pieces. One clear subject in the centre, lots of air around it.
Palette: white and soft grey, near-black details, lake blue and teal as the main colour, plus the single accent named below.
No orange, no dark backgrounds, no neon, no glow, no text or letters, no logos, no screens showing an interface.
